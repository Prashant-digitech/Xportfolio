# CosmosX - Interactive Product Design Case Study
Designed by Prashant Sisodhiya

- index.html : self-contained case study (boards embedded as WebP, opens offline; fonts load from Google Fonts when online)
- assets/boards/ : original full-resolution PNG boards (source)
- cosmosx-assets.json : asset manifest

Open index.html in any modern browser. Keys: Left/Right = chapter, Home/End = first/last, Esc = close viewer.

Evidence notes: research counts (Ch3), personas/quotes (Ch4) and outcome metrics/testimonials (Ch10) come from the boards without source data and are marked UNVERIFIED / CONCEPT. Attach data or edit the `C` array in index.html before publishing.
