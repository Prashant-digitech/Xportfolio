01 // Problem Space & Research

The Challenge: Fragmented Legacy Tools vs. Agentic Intelligence

Modern users seeking strategic and personal foresight lack a cohesive platform that combines rigorous qualitative data-science forecasting with deep esoteric analysis. Existing tools suffer from Windows 95 UI aesthetics, black-box AI reasoning, and fragmented calculator workflows.

Three Friction Points Solved

  • Fragmented Workflows: Eliminates jumping between birth chart calculators, generic LLM prompts, and manual booking chats.
  • Black-Box Distrust: Solved with live WebSocket reasoning terminals showcasing the Research, Analyst, and Forecaster sub-agents in real time.
  • Outdated Usability: Replaces clunky tabular software with an immersive, WCAG AA compliant Golden Celestial Glassmorphism workspace.

Target Personas & JTBD

Persona A // Strategic Planner

Persona B // Self-Optimization Enthusiast

Persona C // Professional Astrologer

Calculates high-precision charts, compares compatibility indices (out of 36), and exports McKinsey-grade PDF reports for clients.

02 // Wireframe & Interface Architecture

The 7 Core Operating System Screens

Each screen was engineered from low-fidelity wireframe to high-fidelity implementation to solve specific user cognitive loads. Click any screen to view in full resolution.

Screen 01 • Telemetry Hub

The Interactive Dashboard (Forecasting & RAG)

The command center features a unified natural language predictive console, a document dropzone for grounding custom enterprise data, and real-time tracking of active forecasts.

  • Custom file uploader for PDF/DOCX personal grounding
  • Predictive query formulation bar with token suggestions
  • Recent forecast telemetry log with status indicators
Screen 02 • Agentic Observability

Real-Time Agent Execution (WebSocket Logs)

To build unwavering trust in AI predictions, this live terminal streams behind-the-scenes LangGraph reasoning steps from the Research, Analyst, and Forecaster sub-agents.

  • Live token stream showing intermediate tool calls and calculations
  • Interactive timeline markers for planetary transit computations
  • Sub-agent consensus score and validation guardrails
Screen 03 • Strategic Synthesis

Telemetry & Scenario Projections

Presents the final AI forecast in structured Markdown, featuring side-by-side 'Best Case' and 'Worst Case' probabilistic scenarios with tailored mitigation strategies.

  • Probabilistic scenario trees with risk sensitivity levers
  • Actionable Vedic remedies and timing windows (Muhurta)
  • One-click high-resolution PDF report generation
Screen 04 • Computer Vision

Palmistry Biometric Scanner

Leverages vector computer-vision wireframe overlays to detect and analyze primary palm creases (Life, Head, Heart lines) and mount elevations.

  • Real-time crease line length and angle vector mapping
  • Chirognomy mount density analysis (Jupiter, Saturn, Venus)
  • Integrated life domain vitality and focus indicators
Screen 05 • Multi-Variable Matching

Kundli Compatibility (Ashta Koota 36-Point)

Provides a visual breakdown of the authentic Vedic 8-factor matching matrix (Varna, Vashya, Tara, Yoni, Graha Maitri, Gana, Bhakoot, Nadi) totaling 36 points.

  • Interactive breakdown of each Koota score with dosha flags
  • Planetary house overlays between partner birth charts
  • Comprehensive harmony index with remediation recommendations
Screen 06 • Chronological Cycles

KP Dasha Timeline & Planetary Periods

Chronologically plots Mahadasha, Antardasha, and Pratyantardasha planetary cycles against user milestones, correlating timing with planetary Shadbala strengths.

  • Gantt-style interactive life timeline from birth to 120 years (Vimshottari)
  • Sub-lord significator tables based on Krishnamurti Paddhati
  • Critical window alerts for career transitions and major life events
Screen 07 • Specialized Agents

AI Astrologer Advisors Marketplace

Enables users to connect directly with specialized AI persona advisors (Vedic KP specialist, Western Hellenistic scholar, Lal Kitab Remedy expert) in structured chat interfaces.

  • Custom persona system prompts and domain expertise certifications
  • Direct conversation history with automated chart context passing
  • Seamless report ordering and voice note audio responses
